# Модуль приоритизации объектов электросети

Интерактивный React-прототип модуля приоритизации объектов электросети для формирования ремонтной программы по техническому состоянию.

## Описание

Прототип реализован в соответствии с Техническим заданием (версия 0.1, Апрель 2025) и демонстрирует следующие возможности:

### Основной экран «Рекомендации»

- **Панель фильтров**: выбор года планирования, типа актива (ВЛ, КЛ, ТП, КТП, ПС), класса напряжения (0,4–220 кВ), категории приоритета
- **Строка статистики**: количество объектов в категориях «Критичный», «Высокий», «Средний» и включённых в план
- **Матрица риска 5×5**: интерактивная визуализация портфеля объектов в координатах «вероятность отказа × последствия отказа»
- **Таблица объектов**: сортировка по убыванию итогового балла приоритета

### Боковая панель детализации (Drawer)

При клике на объект открывается панель с подробной информацией:
- Итоговый балл и категория приоритета
- Декомпозиция балла по четырём компонентам:
  - D — дефектная нагрузка (40%)
  - W — износ (25%)
  - C — последствия отказа (20%)
  - T — результаты испытаний (15%)
- Список открытых дефектов с указанием степени критичности
- Рекомендация вида ремонта (КР / СР / ТР / ТО) с обоснованием
- Кнопки действий: «В план» / «Отложить»

### Матрица риска

- Ось Y (вероятность отказа): производная от компонент D, W, T
- Ось X (последствия отказа): производная от компоненты C
- Зоны матрицы соответствуют стандарту ISO 31000:
  - Красная зона — критический риск
  - Оранжевая зона — высокий риск
  - Жёлтая зона — средний риск
  - Зелёная зона — низкий риск
- Клик по ячейке фильтрует таблицу объектов

### Статусная модель

Объекты могут находиться в следующих статусах:
- **Рекомендован** — объект рассчитан системой и рекомендуется к включению в план
- **Включён в план** — планировщик принял решение о включении объекта в ремонтную программу
- **Отложен** — объект перенесён на будущий период с указанием причины и целевого года

## Технологический стек

- **React 19** — библиотека для построения пользовательского интерфейса
- **Ant Design 5** — UI-библиотека компонентов
- **Vite** — сборщик проектов
- **JavaScript (ES6+)** — язык разработки

## Запуск прототипа

### Требования

- Node.js версии 18 или выше
- npm версии 9 или выше

### Установка зависимостей

```bash
cd scoring-prototype
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

После запуска откройте браузер и перейдите по адресу, указанному в консоли (обычно `http://localhost:5173`).

### Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут помещены в папку `dist`.

## Демо-данные

Прототип содержит демонстрационные данные для 6 объектов различных типов:
- ВЛ-10 кВ «Северная» (критичный приоритет, блокирующий дефект)
- ТП-156 (высокий приоритет)
- КЛ-6 кВ «Центральная» (средний приоритет)
- ПС-110 кВ «Южная» (критичный приоритет)
- КТП-250 (низкий приоритет)
- ВЛ-35 кВ «Западная» (включён в план)

## Реализованные требования ТЗ

### Раздел 3. Скоринговая модель
- ✅ Общая формула расчёта приоритета P = wD×D + wW×W + wC×C + wT×T
- ✅ Компонента D — дефектная нагрузка с мультипликаторами по степеням
- ✅ Компонента W — износ на основе отношения возраста к нормативному сроку
- ✅ Компонента C — последствия отказа (прокси-версия)
- ✅ Компонента T — результаты испытаний
- ✅ Категории приоритета (Критичный / Высокий / Средний / Низкий)
- ✅ Рекомендация вида ремонта по детерминированным правилам

### Раздел 4. Матрица риска
- ✅ Матрица 5×5 с осями «Вероятность» и «Последствия»
- ✅ Цветовое кодирование зон риска
- ✅ Интерактивность: клик по ячейке фильтрует таблицу

### Раздел 6. Требования к пользовательскому интерфейсу
- ✅ Панель фильтров (год, тип актива, напряжение, приоритет)
- ✅ Строка статистики с карточками-метриками
- ✅ Таблица объектов с обязательными столбцами
- ✅ Боковая панель детализации (Drawer)
- ✅ Модальное окно «Отложить объект»

## Примечания
